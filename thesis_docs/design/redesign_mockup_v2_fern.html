Click the bubble on the screen edge to open the panel. The dot shows the worst result of the last check.

How it works

  1. The bubble floats above every window and snaps to the nearest screen edge. Drag to move it.
  2. Click it to open the panel. Select screen area dims the screen; drag a rectangle over any fabric photo, video frame or camera feed.
  3. The result opens in the panel: verdict first, then each defect with its 4-point score. Click a defect to see likely causes, remedy and prevention.

New in v2

  • When nothing is found the verdict reads No defects detected with a reminder to check visually. It never says "acceptable".
  • Each defect shows its ASTM D5430 points. With a ruler in the photo the points use real millimetres.
  • Every check is saved to your inspection history (MongoDB) and appears on the web dashboard.
  • Runs the model locally or on the server; the panel header shows which.

The bubble floats over any app: the camera, WhatsApp, the gallery or a supplier's PDF.

How it works

  1. Install the APK once. Android asks for Display over other apps; this is what allows the bubble.
  2. Tap the bubble. Android asks to allow screen capture for this session, then the screen dims.
  3. Drag the corners over the fabric and tap Analyse area. The result slides up as a sheet over the current app.

New in v2

  • A real floating bubble on Android, built as a native app (React Native).
  • The model runs on the phone when it can and falls back to the server, so older phones work too.
  • Results sync to the same history as Windows and the web dashboard.

Android rules

Screen capture permission is asked once per session; Android does not allow skipping it. The APK is shared as a file, not through the Play Store.

Sending screenshot for analysis…

Tap the AssistiveTouch button, then Fabric Check. The Shortcut takes a screenshot and sends it for analysis.

One-time setup on the iPhone

  1. Open the shared link and tap Add Shortcut (Fabric Check).
  2. Settings → Accessibility → Touch → AssistiveTouch → turn on.
  3. Customise Top Level Menu → replace one icon with Fabric Check. Optionally set Single-Tap to Fabric Check for a one-tap bubble.

New in v2

  • Works on iOS 15.8: the phone only takes the screenshot; the model runs on the server.
  • No App Store, no Mac and no Apple developer account needed.
  • The result opens as a sheet over the current app and is saved to the history.

Apple rules

iOS does not let any app draw its own floating button over other apps. AssistiveTouch is Apple's built-in floating button, so it is the bubble on iPhone. The screenshot is the whole screen; you crop it in the result sheet if needed.

React app on Vercel. Every check from every platform lands here.

What it is for

  • Inspections: history from all devices, filter by lot, date and severity, open any result.
  • Upload: analyse photos in the browser, also on phones without the bubble.
  • Knowledge base: edit causes, remedies and severity rules; the bubbles use the edited version right away.
  • Report: export an inspection as a PDF with the 4-point table.

Stack

  • MongoDB Atlas: inspections, knowledge base, users.
  • Express API on Vercel: analysis endpoint used by iPhone and older phones, history and knowledge base.
  • React front end on Vercel.

The bubble is a pick glass

The folding lens textile engineers use to count ends and picks. The reticle carries a 5 mm scale. The dot on its rim shows the last verdict.
