Fabric Check on iPhone

Apple does not let any app draw its own floating bubble. On iPhone the bubble is Apple's AssistiveTouch button: tap it, tap Fabric Check, and the fabric on your screen is analysed. One-time setup, about 5 minutes.

1. Make the Fabric Check shortcut

  1. Open the Shortcuts app, tap +, and name the shortcut Fabric Check.
  2. Add the action Take Screenshot.
  3. Add Resize Image. Set it to Longest Edge, 1600.
  4. Add Convert Image. Choose JPEG, quality about 80%.
  5. Add Get Contents of URL and paste the address below. Tap Show More: Method POST, Request Body File, and choose Converted Image as the file.
  6. Add Quick Look. It shows the result.

2. Put it on the AssistiveTouch button

  1. Open Settings → Accessibility → Touch → AssistiveTouch and switch it on. A round button appears on the screen.
  2. Tap Customise Top Level Menu, tap one icon, and choose Fabric Check (under Shortcuts).
  3. Optional, for one tap: under Custom Actions set Double-Tap to Fabric Check.

3. Use it

  1. Show the fabric on the screen: the camera, a photo, WhatsApp, a PDF.
  2. Tap the AssistiveTouch button, then Fabric Check.
  3. The result opens in a few seconds: the verdict, the marked photo, and for each defect the likely causes, remedy and prevention.

The first time, iPhone asks to allow the shortcut to send the screenshot to fabric-inspector.vercel.app. Tap Allow. The screenshot is the whole screen, so fill the screen with fabric. It is analysed on the server and not stored. To add shade or bow/skew, end the address with &shade=1&skew=1.
