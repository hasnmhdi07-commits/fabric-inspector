About this app

How it works. 1) A YOLO11 neural network detects hole/tear, stain, slub/neps and broken pick/end. 2) Shade: CIELAB colour difference ΔE CMC(2:1) with a heat map. 3) Bow/skew: weft-line angle across the width (ASTM D3882 definitions). 4) A rule-based knowledge base (4-point system ASTM D5430) gives severity, likely causes, remedy and prevention - it never invents causes.

Photo tips. Fabric flat, camera straight above, even daylight, no shadows. Add a ruler for real sizes.

Data. Trained on public datasets: Fabric Stain Dataset (Univ. of Moratuwa, CC0) and Roboflow Universe projects (CC BY 4.0) by aitex-data-set-waiandt, fault-annotations, pulak-deb-roy, defects-zxmr5, defect-dataset, projectcollege-msi80, fabric-defect-detection-6xxtk. Example images: Fabric Stain Dataset (CC0), defects-zxmr5 (CC BY 4.0), synthetic.

Thesis prototype - decision support for a trained inspector, not a replacement.
